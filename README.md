# QuickLunch: Módulo de Menú

QuickLunch es un sistema web desarrollado con Django y Python para la gestión de productos y menús de un servicio de alimentación. Permite registrar, consultar y administrar productos, utilizando una base de datos relacional (MySQL) y una interfaz sencilla e intuitiva.

## Instalación del entorno Python

1. Clona el repositorio con Git:

```
git clone https://github.com/Yokoperron/QUICKLUNCH/tree/main
```

2. Crea un ambiente virtual de Python en el directorio creado por el comando anterior:

```
python -m venv .venv
```

O si usas Windows:

```
py -m venv .venv
```

3. Activa el entorno virtual:

```
.venv\Scripts\activate
```

4. Instala los módulos requeridos:

```
pip install -r requirements.txt
```
